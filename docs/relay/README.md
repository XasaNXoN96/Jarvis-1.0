# Своё реле для Джарвиса (Cloudflare Workers)

Зачем: если ваша сеть блокирует ИИ, Telegram или загрузки, а на компьютере нельзя держать VPN, Джарвис может ходить через маленький сервер **вне блокировки**. Он ваш, в вашем аккаунте Cloudflare, бесплатного тарифа обычно хватает.

**Честно о пределах.** Реле работает, только пока сам Cloudflare открыт из вашей сети. Если закрыт и он, нужен другой сервер (свой VPS) и прокси на нём (см. «Сеть и обход блокировок» в настройках). Этот файл я не запускал в настоящем Cloudflare: это шаблон, его надо развернуть и проверить у вас.

## Как развернуть
1. Зарегистрируйтесь на cloudflare.com (бесплатно), откройте Workers & Pages, «Create», «Hello World».
2. Замените код воркера содержимым `worker.js` из этой папки.
3. В настройках воркера (Settings, Variables and Secrets) добавьте секрет `RELAY_SECRET`: длинное случайное слово, не короче 16 символов (например, 32 случайные буквы и цифры). Никому его не показывайте.
4. Адрес воркера: `https://<имя>.<ваш-аккаунт>.workers.dev`.

## Как указать Джарвису
Адреса пишутся так: `https://<воркер>/<RELAY_SECRET>/<хост>/<путь>`.
- **ИИ:** Настройки, ИИ, поле «Адрес сервера»: `https://<воркер>/<RELAY_SECRET>/api.openai.com/v1` (для другого провайдера подставьте его хост, он должен быть в списке `ALLOWED` в `worker.js`).
- **Telegram:** Настройки, Подключения, «Сеть и обход блокировок», поле «Своё реле для Telegram»: `https://<воркер>/<RELAY_SECRET>/api.telegram.org`.

Реле пропускает только хосты из списка `ALLOWED`. Чтобы добавить хост, допишите его в список и опубликуйте воркер снова.

## Что учесть
- Через реле проходят ваши ключи и токены (как и через любой прокси), поэтому разворачивайте его только в своём аккаунте и держите `RELAY_SECRET` в тайне. Сменить секрет можно в любой момент: старые адреса перестанут работать.
- Реле ничего не хранит и не пишет в журнал (в коде этого нет), но Cloudflare видит запросы так же, как любой хостинг.
- Бесплатный тариф ограничивает число запросов в сутки; для голосовых ответов и обновлений обычно хватает.
