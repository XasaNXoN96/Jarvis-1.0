# Ручной чек-лист на реальном Windows-ПК

Отмечайте **PASS / FAIL / НЕ УДАЛОСЬ ПРОВЕРИТЬ** и записывайте, что именно видели. CI этого не заменяет: у раннера нет микрофона, колонок и телефона.

## A. Установка
1. Поставьте **большой** установщик в папку по умолчанию. Запустите Jarvis. На главной нет красной ошибки, кроме отсутствующих настроек ИИ.
2. Поставьте поверх (обновление) при запущенной программе: старая закрылась, настройки и диалоги на месте.
3. Папка установки: «Свойства → Безопасность»: ваша учётная запись и SYSTEM/Администраторы; группа «Пользователи» — не больше «чтение и выполнение».
4. Удалите программу: ответ «оставить данные» сохраняет настройки; файлов `ui_token`, `remote_token`, `telegram.json` в `%APPDATA%\com.priler.jarvis` больше нет.

## B. Микрофон и голос
1. Settings Windows → Звук: микрофон включён. В Jarvis (Настройки → Голос) выберите устройство. Статус голоса «Готов», а не «Голос недоступен».
2. Отключите микрофон физически/в системе: Jarvis пишет точную причину и инструкцию, **не** «Слушаю».
3. Скажите «Джарвис, который час»: распознал (текст появился), ответ, озвучено ли вслух.
4. «Проверь голос» (диагностика): голос Piper установлен? Если нет — «Установить голос Джарвиса» доходит до «Готово».
5. Piper → Opus → Vosk: отправьте голосовое сообщение в Telegram-бот (если включён): ответ пришёл, распознанный текст верный.

## C. Русский текст и буфер обмена
Скопируйте абзац с «ё», кавычками «», тире, эмодзи и латиницей; «Джарвис, прочитай буфер»: читает без ошибки кодировки, нет сообщения про UTF-8, длинный текст обрезается по символам.

## D. Телефон
1. Система → «Пульт телефона»: включить; QR-код и ссылка показываются; телефон в той же Wi-Fi сети открывает ссылку.
2. Мои устройства: появился «Телефон (пульт)», статус «в сети», последняя связь «только что». Заряд показан **только если** браузер телефона его сообщает.
3. «Найти телефон» — звук на телефоне; «Остановить сигнал».
4. Закройте страницу на телефоне / отключите Wi-Fi: в первые ~30 с статус «подключение», потом «не в сети»; откройте снова: возвращается «в сети» без новой ссылки.
5. «Новая ссылка»: старая на телефоне перестаёт работать.
6. Из любой сети (мобильный интернет, без VPN): включите переключатель, откройте ссылку по мобильной сети; выключите: ссылка перестаёт открываться.
7. Подберите 10+ неверных токенов подряд в адресе: после десятого — «слишком много попыток» (429).

## E. Главная и «Система»
1. Главная: три индикатора «ПК · ИИ · Телефон» с текстом; нажмите — раскрылись карточки; сфера, поле ввода, микрофон и «Отправить» не перекрыты. Сожмите окно по высоте (<780 px): карточки скрылись, остались индикаторы. Нет горизонтальной прокрутки при 125–150 % масштабе.
2. Цвета не единственный признак: каждый индикатор подписан словом.
3. Система: все три карточки (компьютер, ИИ, пульт), «Проверить подключение», «Настройки ИИ», переключатель пульта, QR, «Копировать ссылку», «Новая ссылка», «Из любой сети», форма «Ссылка или текст для телефона».
4. Мои устройства: «Этот компьютер» (на ноутбуке с батареей — «Ноутбук» и заряд), микрофоны списком; нет выдуманных устройств; «Подробнее» показывает функции с честными «не поддерживается».

## F. Безопасность (глазами пользователя)
1. Команда «закрой блокнот» спрашивает подтверждение; «да» из другого источника (телефон) не подтверждает команду, заданную голосом.
2. Командой нельзя записать в `C:\Windows`, `Program Files`, папку Jarvis, `%APPDATA%\com.priler.jarvis`.
3. Другой пользователь Windows (вторая учётная запись) не может открыть `%APPDATA%` первого и порт 9714 без токена.

## G. Object Interaction Engine (ручные испытания на Windows)

**Статус: ни один пункт этого раздела не проверен на настоящих программах.** Автоматические тесты используют поддельные Word/Excel и подставной ИИ; это проверка логики, а не замена этим испытаниям. Отмечайте пункт только после запуска на настоящей программе: `[ ] не проверено` → `[x] PASS` / `[x] FAIL` + дата и заметка.

Общее для всех сценариев:
* **Как безопасно остановить:** кнопка «Стоп» на главной (строка объекта), либо голосом «стоп» / «пауза» / «отмена». Программа и документ при этом остаются открытыми и ничего не удаляется. Если Jarvis не реагирует — закройте окно Jarvis кнопкой в трее («Выход»): Word/VS Code это не закроет и файлы не тронет.
* **Общие признаки ошибки:** текст появился в другом окне; Jarvis сказал «сохранено/готово», а файла нет; документ закрыт или удалён без вашего «да»; код запущен сам; в строке объекта состояние не меняется после «стоп».
* Перед началом: установлена сборка из CI этой ветки, микрофон работает (раздел B), в Word нет важных документов (используйте новые).

### G1. Word: диктовка → стоп → продолжить  `[ ] не проверено`
* **Условия:** установлен Microsoft Word, Jarvis запущен.
* **Действия:** 1) «открой ворд». 2) «начинаем работу с объектом» → «создать новый документ». 3) Продиктуйте: «Привет, как дела? Сегодня мы изучаем информатику». 4) Скажите «стоп». 5) Скажите «да» на «Продолжим?». 6) Продиктуйте ещё предложение.
* **Ожидается:** после шага 3 текст в документе; после «стоп» — диктовка остановилась, документ открыт, Jarvis спросил «Продолжим?», в строке объекта «пауза»; после «да» — диктовка идёт в тот же документ, без дублей.
* **Ошибка:** слово «стоп» оказалось в документе; текст продублирован; документ закрылся.
* **Особо:** скажите длинную фразу со словом «стоп» внутри («на светофоре горит знак стоп и пауза между словами») — она должна попасть в документ как текст.

### G2. Word: закрыть документ во время диктовки  `[ ] не проверено`
* **Условия:** как G1, идёт диктовка.
* **Действия:** закройте документ в Word (без сохранения), затем продиктуйте фразу. Откройте Блокнот и убедитесь, что в нём ничего не появилось.
* **Ожидается:** Jarvis сообщил, что документ закрыт, предложил открыть его снова (если он был сохранён); текст нигде не напечатан; состояние «ошибка» в строке объекта.
* **Ошибка:** текст появился в другом окне; Word запустился сам и создал новый документ.

### G3. Word: исправление ошибок ИИ и подтверждение замены  `[ ] не проверено`
* **Условия:** настроен ИИ-провайдер (раздел «Система»), в документе фраза с ошибками («Превет мир»).
* **Действия:** 1) «исправь ошибки в документе». 2) Дождитесь вопроса «Заменить?». 3) Скажите «нет» — проверьте, что текст не изменился. 4) Повторите и скажите «да». 5) Скажите «отмени последнее действие».
* **Ожидается:** до «да» текст прежний; после «да» заменён и Jarvis сказал, что проверил чтением; «отмени…» вернул прежний текст; «сохранено» Jarvis не говорит, пока вы не сохранили.
* **Ошибка:** замена без «да»; документ изменён после «нет».
* **Остановка:** «стоп» во время «Работаю над текстом» — документ не меняется, поздний ответ не вставляется.

### G4. Word: документ изменён между чтением и «да»  `[ ] не проверено`
* **Действия:** запустите «исправь ошибки», после вопроса «Заменить?» допишите в документе вручную слово, затем скажите «да».
* **Ожидается:** Jarvis отказывается заменять («текст изменился»), ваша правка осталась.
* **Ошибка:** текст заменён и ваша правка потеряна.

### G5. Word: автозамена Word при вставке  `[ ] не проверено`
* **Действия:** «напиши вступление про информатику» (ИИ вернёт текст с кавычками/тире).
* **Ожидается:** текст вставлен; Jarvis сказал «проверил чтением» (типографские кавычки, тире и многоточие Word — не ошибка).
* **Ошибка:** ложное «подтвердить не удалось» при совпадающем тексте — сообщите, приложите текст документа.

### G6. Блокнот  `[ ] не проверено`
* **Условия:** Windows Блокнот.
* **Действия:** «начинаем работу с объектом» → «блокнот» → продиктуйте → «стоп» → «да» → закройте Блокнот (без сохранения) и скажите фразу.
* **Ожидается:** текст только в окне Блокнота; после закрытия — сообщение, что Блокнот закрыт, текст не напечатан в другом окне.
* **Ошибка:** текст в другом окне.

### G7. VS Code + Python  `[ ] не проверено`
* **Условия:** установлен VS Code и Python, настроен ИИ-провайдер, папки «Документы» доступна.
* **Действия:** 1) «открой вс код». 2) «создай python файл» → на вопрос имени «назови calculator.py» → на вопрос папки «в документах папка проверка». 3) «напиши калькулятор на Python». 4) «добавь обработку деления на ноль». 5) «проверь синтаксис». 6) «верни как было». 7) Повторите шаг 2 с тем же именем.
* **Ожидается:** файл создан и открыт в VS Code; код записан целиком, Jarvis сказал число строк и результат проверки синтаксиса и «код не запускался»; шаг 4 правит тот же файл; шаг 7 — «файл уже есть, я его не менял».
* **Ошибка:** код выполнился (появились побочные файлы/окна); существующий файл перезаписан; нет сообщения о результате.
* **Особо:** «запусти код» — Jarvis должен отказаться.

### G8. Отмена запроса к ИИ  `[ ] не проверено`
* **Условия:** настроен ИИ-провайдер.
* **Действия:** запустите G7 шаг 3 (или G3 шаг 1) и сразу скажите «стоп» (или нажмите «Стоп» на главной).
* **Ожидается:** Jarvis: «Генерация отменена…», в строке объекта «пауза»; файл/документ не изменён даже если ИИ ответит позже; «продолжим с объектом» возвращает к работе.
* **Ошибка:** после стопа файл или документ изменился; кнопка «Стоп» неактивна во время генерации.

### G9. Настоящий WebView2: строка объекта и кнопка «Стоп»  `[ ] не проверено вручную`
* **Условия:** установленный Jarvis (окно WebView2), главная страница.
* **Действия:** в покое строки объекта нет; запустите G1/G8 и наблюдайте строку; измените размер окна (узкое, полноэкранное); нажмите «Стоп».
* **Ожидается:** строка показывает состояние и объект, не перекрывает сферу, поле ввода и кнопки при любых размерах; «Стоп» активна при диктовке/генерации/вопросе и возвращает честное сообщение.
* **Ошибка:** наложение элементов, горизонтальная прокрутка, строка остаётся после окончания работы.
* **Автоматическая часть:** `webview2-e2e.js` в CI проверяет в настоящем WebView2 отрисовку строки для всех состояний (состояние подставляет страница) и честный ответ «Стоп» настоящего бэкенда в покое; поведение при настоящем AI_TASK автоматом не проверяется.
