# Игровой режим: голосовое управление игрой и помощь прицела

Только для **одиночных (офлайн) игр**. Не включайте в онлайн-играх и в сетевых режимах: правила игр и античиты запрещают такие помощники, аккаунт могут заблокировать.

## Что это и чем не является
Программа только **шлёт нажатия клавиш и движения мыши** средствами Windows (как клавиатура и мышь) и **снимает картинку экрана** (как программа для скриншотов). Она **не читает память игры, ничего в неё не внедряет и не трогает её файлы**.

## Как включить и выключить
- Скажите (или напишите, или скажите в пульт на планшете): **«Джарвис, включи голосовое управление для игр»** (подойдут «включи игровой режим», «давай игровой режим»). Это платная функция (Premium).
- Выключить: **«выключи игровой режим»**, «хватит играть». Или кнопки в Настройки → Общие → «Игровой режим».
- Режим **работает только пока впереди окно игры из списка** (по умолчанию `iw3sp.exe` Call of Duty 4, `iw4sp.exe` Modern Warfare 2, `iw5sp.exe` Modern Warfare 3, все три — одиночные кампании). В другом окне фразы ничего не делают, а зажатые клавиши отпускаются сами.

## Другие офлайн-игры: «добавь эту игру»
1. Откройте свою одиночную игру (окно должно быть впереди; лучше «окно без рамки»).
2. Скажите **«Джарвис, включи игровой режим»**, потом **«добавь эту игру»** (можно «запомни эту игру»). Программа возьмёт имя программы окна, которое сейчас впереди, и запомнит его в `game_list.json` в папке данных.
3. Теперь игра работает в игровом режиме с **обычными клавишами** (W A S D, пробел, C, Shift, R, G, V, F). Если в игре другие клавиши или другая чувствительность мыши, пропишите их в `game_profile.json` в разделе `games` (пример ниже).
4. Убрать: откройте игру и скажите **«забудь эту игру»**. Игры из списка по умолчанию так не убираются.

## Жанры: шутер, гонки, экшен / приключения (и любые другие через свои фразы)
При добавлении игры можно назвать жанр: **«добавь эту игру как гонку»**, **«…как экшен»** (подходят «как приключение», «как РПГ», «как платформер»), **«…как шутер»**. Жанр можно сменить позже той же фразой. Без названия игра понимает общие фразы и фразы шутера.

| Жанр | Что можно сказать (кроме общих: иди, беги, стой, смотри налево, прыгай, присядь, используй) |
|---|---|
| **Гонки** | **газ** / гони / поехали (удерживает W), **тормоз** / задний ход (S), **влево** / **вправо** (руль, A / D), **прямо** (отпускает руль), **ручник** / дрифт (пробел), **нитро** / турбо (Shift), **сигнал** (H), **смени камеру** (C) |
| **Экшен / приключения / РПГ** | **атакуй** / бей / руби (левая кнопка), **тяжёлый удар** (удержание), **блок** (правая кнопка удерживается) и **сними блок**, **перекат** / уворот (Ctrl), **инвентарь** (I), **карта** (M), **полечись** / аптечка (X), **садись в машину** / залезь (F) |
| **Шутер** | как раньше: стреляй, очередью, целься, перезаряди, граната, нож и т. д. |

Клавиши этих фраз — предположение об обычных настройках; свои клавиши для каждой игры задаются в `game_profile.json` (`games` → имя программы → `keys`; новые имена: `handbrake`, `nitro`, `horn`, `camera`, `dodge`, `inventory`, `map`, `heal`).

### Свои фразы для любой игры (любой жанр)
Если жанра в списке нет (стратегия, симулятор, платформер, головоломка…), придумайте свои фразы в `game_profile.json`: слово или фраза и список шагов.
```json
{
  "phrases": { "на ура": ["hold:w", "wait:500", "tap:space"], "прицельный выстрел": ["click:right", "wait:50", "click:left"] },
  "games": { "mygame.exe": { "genre": "action", "phrases": { "тяжёлая атака": ["hold:shift", "click:left", "release:shift"] } } }
}
```
Шаги: `tap:клавиша`, `hold:клавиша` (держится до «стой»), `release:клавиша`, `click:left` / `click:right`, `wait:миллисекунды` (до 2000), `move:dx,dy` (мышь, до 1500). До 60 фраз, до 30 шагов в фразе. Клавиши только обычные игровые (буквы, цифры, space, shift, ctrl, tab). Нельзя назвать фразу словами остановки или выключения («стой», «стоп», «выключи», «хватит»). Фразы конкретной игры стоят раньше общих.

**Что программа не добавит:** известные сетевые игры (Valorant, CS2, Fortnite, Apex, Overwatch, Rainbow Six, PUBG, Dota 2, League of Legends, Tarkov и другие; список неполный) и программы, которые не игры (проводник, командная строка, браузеры, Word, Telegram, Steam, сама программа Джарвис и т. д.).

**Защита от читов:** пока запущена программа защиты (**EasyAntiCheat, BattlEye (`BEService`), Vanguard (`vgc`), FACEIT, ESEA, PunkBuster, GameGuard, XIGNCODE**), игровой режим **не включается**, а включённый сам выключается, клавиши отпускаются. Это защита от случайного запуска в онлайн-играх; она не гарантия: я проверяю только эти программы и только пока они запущены. За использование в сетевых играх отвечаете вы.

Пример `game_profile.json` со своими клавишами для отдельной игры:
```json
{ "games": { "mygame.exe": { "px_per_90": 300, "keys": { "forward": "w", "crouch": "ctrl", "melee": "e" } } } }
```


## Фразы (в игровом режиме)
| Что сказать | Что происходит |
|---|---|
| иди вперёд / назад / влево / вправо | зажимает W / S / A / D и держит, пока не скажете «стой» |
| беги / бегом | вперёд + спринт |
| стой / стоп / замри | отпускает все клавиши и кнопки |
| смотри налево / направо / вверх / вниз | поворот камеры (по умолчанию 30°) |
| поверни налево на 90 градусов, смотри чуть правее, резко поверни направо | угол задан числом, «чуть» = 15°, «резко» = 60° |
| разворот, оглянись, посмотри назад | поворот на 180° |
| стреляй / огонь | короткая очередь; «огонь очередью» — длинная |
| прекрати огонь, не стреляй | отпускает кнопку огня |
| целься / не целься, опусти оружие | правая кнопка мыши зажата / отпущена |
| перезаряди, брось гранату, ударь ножом, прыгай, присядь, используй, открой дверь | нажатие нужной клавиши |
| выключи игровой режим | выход из режима |
| добавь эту игру [как гонку / как экшен] / забудь эту игру | список ваших игр (см. ниже) |

## Свои клавиши и игры (файл `game_profile.json`)
Файл лежит в папке данных Джарвиса (рядом с остальными его файлами); если его нет, берутся клавиши по умолчанию. Пример:
```json
{
  "title": "Моя игра",
  "exes": ["mygame.exe"],
  "px_per_90": 450,
  "keys": { "forward": "w", "back": "s", "left": "a", "right": "d", "jump": "space", "crouch": "c",
            "sprint": "shift", "reload": "r", "grenade": "g", "melee": "v", "use": "f" },
  "aim": { "strength": 25, "head": 12, "radius": 260, "conf": 45, "class": 0, "model": "D:\\ai\\player.onnx" }
}
```
- `exes` — имена программ игры (только имя файла, `.exe`). Узнайте его в диспетчере задач.
- `px_per_90` — на сколько единиц мыши поворот на 90°. Зависит от чувствительности мыши в игре: подберите так, чтобы «поверни налево на 90 градусов» поворачивало на четверть круга.
- В `keys` разрешены только обычные игровые клавиши: буквы, цифры, `space`, `shift`, `ctrl`, `tab`. Alt, клавиша Windows, Esc и стрелки запрещены. Если файл с ошибкой, режим включится с обычными клавишами и скажет, что не так.
- Клавиши по умолчанию — предположение о настройках по умолчанию; если в вашей игре они другие, поправьте файл.

## Помощь прицела (эксперимент, выключена при каждом запуске)
Включить: **«включи помощь прицела»** (после включения игрового режима) или кнопка в настройках. Выключить: «выключи помощь прицела».
Как работает: пока вы **держите правую кнопку мыши** в окне игры, программа снимает квадрат 640×640 вокруг прицела, нейросеть-детектор находит людей, берётся ближайший к прицелу (в пределах `radius`), и мышь в каждом кадре немного (`strength`% оставшегося пути, не больше 40 точек) подводится к его голове. Голова = верхняя часть рамки человека (`head`% высоты сверху).

Нужна **модель детектора** — файл `.onnx` по умолчанию в `<папка данных>/aim/player.onnx`. Программа её не содержит. Получить общую модель YOLOv8 (человек = класс 0):
```
pip install ultralytics
yolo export model=yolov8n.pt format=onnx imgsz=640
```
Файл `yolov8n.onnx` положите как `aim/player.onnx`. Входной тензор должен называться `images`, выход — `output0` (так экспортирует YOLOv8).

### Что честно ограничено
- Модель общего назначения находит **человека целиком**, а голову программа оценивает по верху рамки: грубо. Для точности в голову нужно **дообучить** модель на скриншотах вашей игры (ниже).
- Снимок экрана работает с игрой в режиме **«окно без рамки» (borderless)**. В «настоящем» полноэкранном режиме снимок часто чёрный, и программа напишет об этом.
- В этой сборке нейросеть считается **на процессоре**. На i5-11400 один кадр 640×640 у YOLOv8n займёт порядка десятков миллисекунд (оценка, не измерение): это 15–30 кадров в секунду. Версия на видеокарте (DirectML) в сборку **не включена**.
- Принимает ли игра искусственное движение мыши, проверяется только на вашем компьютере.
- В «Диагностике»/настройках видно, сколько миллисекунд занимает кадр.

## Дообучение детектора на скриншотах игры (по желанию, повышает точность головы)
1. Включите игру в режиме «окно без рамки» и сделайте 500–1000 скриншотов с врагами в разных местах (клавиша Print Screen, папка скриншотов Windows, или игровая функция скриншотов).
2. Разметьте: нарисуйте рамки вокруг **головы** (отдельный класс `head`) и, если хотите, вокруг тела. Для разметки подойдут бесплатные программы (CVAT, Label Studio, Roboflow). Чтобы ускорить, сначала прогоните кадры общей моделью и поправьте результат.
3. Обучите: `yolo detect train data=data.yaml model=yolov8n.pt imgsz=640 epochs=50`.
4. Экспортируйте: `yolo export model=runs/detect/train/weights/best.pt format=onnx imgsz=640`.
5. Положите файл как `aim/player.onnx`, а в `game_profile.json` укажите `"aim": { "class": <номер класса головы> }`. Тогда цель — сама голова (в этом случае поставьте `head` = 50, это середина рамки).

Я не обучал такую модель: нет скриншотов вашей игры и нет доступа к этим сайтам из моей среды.

## Что проверено и что нет
Проверено тестами: разбор фраз, удержание и отпускание клавиш, повороты, список игр и защита профиля, разбор вывода YOLO, выбор цели, плавный шаг, и **весь путь картинка → настоящий ONNX Runtime → шаг мыши** с поддельной моделью. Код под Windows собирается. **Не проверено** (нет игры и Windows): работа в самой игре, захват экрана, скорость кадра, точность попадания.
