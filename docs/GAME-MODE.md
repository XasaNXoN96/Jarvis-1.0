# Игровой режим: голосовое управление игрой и помощь прицела

Только для **одиночных (офлайн) игр**. Не включайте в онлайн-играх и в сетевых режимах: правила игр и античиты запрещают такие помощники, аккаунт могут заблокировать.

## Что это и чем не является
Программа только **шлёт нажатия клавиш и движения мыши** средствами Windows (как клавиатура и мышь) и **снимает картинку экрана** (как программа для скриншотов). Она **не читает память игры, ничего в неё не внедряет и не трогает её файлы**.

## Как включить и выключить
- Скажите (или напишите, или скажите в пульт на планшете): **«Джарвис, включи голосовое управление для игр»** (подойдут «включи игровой режим», «давай игровой режим»). Это платная функция (Premium).
- Выключить: **«выключи игровой режим»**, «хватит играть». Или кнопки в Настройки → Общие → «Игровой режим».
- Режим **работает только пока впереди окно игры из списка** (по умолчанию `iw3sp.exe` Call of Duty 4, `iw4sp.exe` Modern Warfare 2, `iw5sp.exe` Modern Warfare 3, все три — одиночные кампании). В другом окне фразы ничего не делают, а зажатые клавиши отпускаются сами.

## Другие офлайн-игры: «добавь эту игру»
1. Откройте свою одиночную игру (окно должно быть впереди; лучше «окно без рамки»).
2. Скажите **«Джарвис, включи игровой режим»**, потом **«добавь эту игру»** (можно «запомни эту игру»). Программа возьмёт имя программы окна, которое сейчас впереди, и запомнит его в `game_list.json` в папке данных.
3. Теперь игра работает в игровом режиме с **обычными клавишами** (W A S D, пробел, C, Shift, R, G, V, F). Если в игре другие клавиши или другая чувствительность мыши, пропишите их в `game_profile.json` в разделе `games` (пример ниже).
4. Убрать: откройте игру и скажите **«забудь эту игру»**. Игры из списка по умолчанию так не убираются.

## Жанры: шутер, гонки, экшен / приключения (и любые другие через свои фразы)
При добавлении игры можно назвать жанр: **«добавь эту игру как гонку»**, **«…как экшен»** (подходят «как приключение», «как РПГ», «как платформер»), **«…как шутер»**. Жанр можно сменить позже той же фразой. Без названия игра понимает общие фразы и фразы шутера.

| Жанр | Что можно сказать (кроме общих: иди, беги, стой, смотри налево, прыгай, присядь, используй) |
|---|---|
| **Гонки** | **газ** / гони / поехали (удерживает W), **тормоз** / задний ход (S), **влево** / **вправо** (руль, A / D), **прямо** (отпускает руль), **ручник** / дрифт (пробел), **нитро** / турбо (Shift), **сигнал** (H), **смени камеру** (C) |
| **Экшен / приключения / РПГ** | **атакуй** / бей / руби (левая кнопка), **тяжёлый удар** (удержание), **блок** (правая кнопка удерживается) и **сними блок**, **перекат** / уворот (Ctrl), **инвентарь** (I), **карта** (M), **полечись** / аптечка (X), **садись в машину** / залезь (F) |
| **Шутер** | как раньше: стреляй, очередью, целься, перезаряди, граната, нож и т. д. |

Клавиши этих фраз — предположение об обычных настройках; свои клавиши для каждой игры задаются в `game_profile.json` (`games` → имя программы → `keys`; новые имена: `handbrake`, `nitro`, `horn`, `camera`, `dodge`, `inventory`, `map`, `heal`).

### Свои фразы для любой игры (любой жанр)
Если жанра в списке нет (стратегия, симулятор, платформер, головоломка…), придумайте свои фразы в `game_profile.json`: слово или фраза и список шагов.
```json
{
  "phrases": { "на ура": ["hold:w", "wait:500", "tap:space"], "прицельный выстрел": ["click:right", "wait:50", "click:left"] },
  "games": { "mygame.exe": { "genre": "action", "phrases": { "тяжёлая атака": ["hold:shift", "click:left", "release:shift"] } } }
}
```
Шаги: `tap:клавиша`, `hold:клавиша` (держится до «стой»), `release:клавиша`, `click:left` / `click:right`, `wait:миллисекунды` (до 2000), `move:dx,dy` (мышь, до 1500). До 60 фраз, до 30 шагов в фразе. Клавиши только обычные игровые (буквы, цифры, space, shift, ctrl, tab). Нельзя назвать фразу словами остановки или выключения («стой», «стоп», «выключи», «хватит»). Фразы конкретной игры стоят раньше общих.

**Что программа не добавит:** известные сетевые игры (Valorant, CS2, Fortnite, Apex, Overwatch, Rainbow Six, PUBG, Dota 2, League of Legends, Tarkov и другие; список неполный) и программы, которые не игры (проводник, командная строка, браузеры, Word, Telegram, Steam, сама программа Джарвис и т. д.).

**Защита от читов:** пока запущена программа защиты (**EasyAntiCheat, BattlEye (`BEService`), Vanguard (`vgc`), FACEIT, ESEA, PunkBuster, GameGuard, XIGNCODE**), игровой режим **не включается**, а включённый сам выключается, клавиши отпускаются. Это защита от случайного запуска в онлайн-играх; она не гарантия: я проверяю только эти программы и только пока они запущены. За использование в сетевых играх отвечаете вы.

Пример `game_profile.json` со своими клавишами для отдельной игры:
```json
{ "games": { "mygame.exe": { "px_per_90": 300, "keys": { "forward": "w", "crouch": "ctrl", "melee": "e" } } } }
```


## Фразы (в игровом режиме)
| Что сказать | Что происходит |
|---|---|
| иди вперёд / назад / влево / вправо | зажимает W / S / A / D и держит, пока не скажете «стой» |
| беги / бегом | вперёд + спринт |
| стой / стоп / замри | отпускает все клавиши и кнопки |
| смотри налево / направо / вверх / вниз | поворот камеры (по умолчанию 30°) |
| поверни налево на 90 градусов, смотри чуть правее, резко поверни направо | угол задан числом, «чуть» = 15°, «резко» = 60° |
| разворот, оглянись, посмотри назад | поворот на 180° |
| стреляй / огонь | короткая очередь; «огонь очередью» — длинная |
| прекрати огонь, не стреляй | отпускает кнопку огня |
| целься / не целься, опусти оружие | правая кнопка мыши зажата / отпущена |
| перезаряди, брось гранату, ударь ножом, прыгай, присядь, используй, открой дверь | нажатие нужной клавиши |
| выключи игровой режим | выход из режима |
| добавь эту игру [как гонку / как экшен] / забудь эту игру | список ваших игр (см. ниже) |

## Свои клавиши и игры (файл `game_profile.json`)
Файл лежит в папке данных Джарвиса (рядом с остальными его файлами); если его нет, берутся клавиши по умолчанию. Пример:
```json
{
  "title": "Моя игра",
  "exes": ["mygame.exe"],
  "px_per_90": 450,
  "keys": { "forward": "w", "back": "s", "left": "a", "right": "d", "jump": "space", "crouch": "c",
            "sprint": "shift", "reload": "r", "grenade": "g", "melee": "v", "use": "f" },
  "aim": { "strength": 25, "head": 12, "radius": 260, "conf": 45, "class": 0, "model": "D:\\ai\\player.onnx" }
}
```
- `exes` — имена программ игры (только имя файла, `.exe`). Узнайте его в диспетчере задач.
- `px_per_90` — на сколько единиц мыши поворот на 90°. Зависит от чувствительности мыши в игре: подберите так, чтобы «поверни налево на 90 градусов» поворачивало на четверть круга.
- В `keys` разрешены только обычные игровые клавиши: буквы, цифры, `space`, `shift`, `ctrl`, `tab`. Alt, клавиша Windows, Esc и стрелки запрещены. Если файл с ошибкой, режим включится с обычными клавишами и скажет, что не так.
- Клавиши по умолчанию — предположение о настройках по умолчанию; если в вашей игре они другие, поправьте файл.

## Помощь прицела (эксперимент, выключена при каждом запуске)
Включить: **«включи помощь прицела»** (после включения игрового режима) или кнопка в настройках. Выключить: «выключи помощь прицела».
Как работает: пока вы **держите правую кнопку мыши** в окне игры, программа снимает квадрат 640×640 вокруг прицела, нейросеть-детектор находит людей, берётся ближайший к прицелу (в пределах `radius`), и мышь в каждом кадре немного (`strength`% оставшегося пути, не больше 40 точек) подводится к его голове. Голова = верхняя часть рамки человека (`head`% высоты сверху).

Нужна **модель детектора** — файл `.onnx` в `<папка данных>/aim/player.onnx`. Программа её не содержит, но умеет сама поставить официальную (см. «Установка модели внутри Jarvis» ниже). Python, командная строка и Ultralytics для этого не нужны.

### Что честно ограничено
- Модель общего назначения находит **человека целиком**, а голову программа оценивает по верху рамки: грубо. Для точности в голову нужно **дообучить** модель на скриншотах вашей игры (ниже).
- Снимок экрана работает с игрой в режиме **«окно без рамки» (borderless)**. В «настоящем» полноэкранном режиме снимок часто чёрный, и программа напишет об этом.
- В этой сборке нейросеть считается **на процессоре** (ONNX Runtime, встроен в программу). Версия на видеокарте (DirectML) в обычную сборку **не включена**: пункт «Видеокарта» в карточке честно переходит на процессор и пишет об этом. Видеокарта не обязательно быстрее для маленькой модели. Время кадра видно в карточке и в «Диагностике» — оценок «на глаз» здесь нет.
- Принимает ли игра искусственное движение мыши, проверяется только на вашем компьютере.
- В «Диагностике»/настройках видно, сколько миллисекунд занимает кадр.

## Дообучение детектора на скриншотах игры (по желанию, повышает точность головы)
1. Включите игру в режиме «окно без рамки» и сделайте 500–1000 скриншотов с врагами в разных местах (клавиша Print Screen, папка скриншотов Windows, или игровая функция скриншотов).
2. Разметьте: нарисуйте рамки вокруг **головы** (отдельный класс `head`) и, если хотите, вокруг тела. Для разметки подойдут бесплатные программы (CVAT, Label Studio, Roboflow). Чтобы ускорить, сначала прогоните кадры общей моделью и поправьте результат.
3. Обучите: `yolo detect train data=data.yaml model=yolov8n.pt imgsz=640 epochs=50`.
4. Экспортируйте: `yolo export model=runs/detect/train/weights/best.pt format=onnx imgsz=640`.
5. Положите файл как `aim/player.onnx`, а в `game_profile.json` укажите `"aim": { "class": <номер класса головы> }`. Тогда цель — сама голова (в этом случае поставьте `head` = 50, это середина рамки).

Я не обучал такую модель: нет скриншотов вашей игры и нет доступа к этим сайтам из моей среды.

## Что проверено и что нет
Проверено тестами: разбор фраз, удержание и отпускание клавиш, повороты, список игр и защита профиля, разбор вывода YOLO, выбор цели, плавный шаг, и **весь путь картинка → настоящий ONNX Runtime → шаг мыши** с поддельной моделью. Код под Windows собирается. **Не проверено** (нет игры и Windows): работа в самой игре, захват экрана, скорость кадра, точность попадания.

## Страница «Игры»

В меню слева есть раздел **Игры**. Всё, что раньше было разбросано по настройкам и голосовым фразам, собрано там.

### Два способа добавить игры

1. **Автоматически.** Кнопка «Найти мои игры» ищет установленные игры Steam (папки библиотек и файлы `appmanifest_*.acf`), Epic Games (манифесты в `ProgramData\Epic`) и GOG (реестр Windows). Подходящие игры добавляются в список сами, жанр подбирается по названию (гонки, экшен, шутер по умолчанию). Остальные показываются с причиной: известная онлайн-игра, программа не игра, рядом найдена защита от читов, не удалось найти программу игры. Файлы игр не изменяются: смотрятся только имена папок и программ.
2. **Вручную.** Поле «Программа игры» (имя файла `game.exe` или полный путь), название и жанр. Так же работает голос: откройте игру и скажите «добавь эту игру».

Известные онлайн-игры и не-игры (браузеры, проводник и т. п.) в список не попадают никаким способом. Список лежит в `game_list.json` в папке данных; у каждой игры можно сменить жанр или убрать её из списка.

### Три добавления для играющего

- **Макросы голосом.** «Запиши макрос комбо» → сделайте нужные нажатия в окне игры → «сохрани макрос». Потом фраза «комбо» повторяет запись. Записываются только игровые клавиши (буквы, цифры, пробел, Shift, Ctrl, Tab) и две кнопки мыши; движение мыши не записывается. До 60 макросов по 30 шагов; хранятся в `game_macros.json`; «удали макрос комбо» или кнопка на странице.
- **Подсказка по экрану и чтение текста.** «Подскажи, что делать», «куда идти» — ответ по снимку экрана; «прочитай текст», «переведи текст» — чтение или перевод надписи. Работает через «Анализ экрана»: он должен быть разрешён в Настройках, нужна модель, которая видит картинки. Снимок уходит только по такой команде.
- **Метка на экране и звук.** Переключатели на странице (выключены по умолчанию): маленькая надпись над игрой («● ИГРОВОЙ РЕЖИМ · W · ПРИЦЕЛ · ЗАПИСЬ «комбо»»), через которую проходят клики мыши, и короткий сигнал, когда фраза выполнена. Метка может быть скрыта игрой в «настоящем» полноэкранном режиме; в игре выберите «окно без рамки».

### Что не проверено на реальной Windows

Поиск Steam/Epic/GOG на настоящих установках, запись макроса, метка на экране, звук подтверждения и подсказки по экрану проверены только тестами разбора и сборкой под Windows; в живой игре они не запускались.

### Защита после аудита

- Фраза из нескольких шагов (макрос, своя фраза из `game_profile.json`) перед каждым шагом проверяет, что окно игры впереди и защита от читов не запущена; иначе остальные шаги не отправляются, клавиши отпускаются. Остановить макрос можно и клавишей Esc.
- Запись макроса сбрасывается (ничего не сохраняется), если режим выключили или запустилась защита от читов.
- Если лицензия закончилась, пока режим включён, следующая игровая фраза выключает режим и отпускает клавиши. «Стой» и «выключи игровой режим» работают всегда.
- Без лицензии страница «Игры» не даёт включить режим, добавить игру, запустить поиск и менять метку/звук; убрать игру, сменить жанр и удалить макрос можно всегда.
- Повреждённый `game_list.json` или `game_macros.json` (или файл с неподходящими записями) не затирается молча: перед записью старый текст сохраняется рядом как `имя.bak-<время>`. Программа никогда не удаляет списки и макросы пользователя сама.

### Макрос можно остановить голосом

Фраза из нескольких шагов (макрос, своя фраза) играет в отдельном потоке по шагам: пауза между шагами ждётся без блокировки программы. Поэтому «стой», «выключи игровой режим» и любая новая игровая фраза останавливают макрос после текущего шага (это доли секунды), а клавиши отпускаются. Esc, уход игры из фокуса и запуск защиты от читов останавливают его тоже. Не проверено на живой Windows: проверяйте на макросе с паузами («тап w, ждать 2 секунды, тап пробел») и словом «стой».

### Диагностика и отчёт по играм

- В «Диагностике» есть карточка **Игровой режим**: режим, окно игры, защита от читов, число игр и макросов, метка, звук, итог последнего поиска. Карточка не утверждает, что игра работает, она показывает только состояние программы.
- Кнопка **Копировать отчёт по играм** (на странице «Игры» и в «Диагностике») копирует текст: состояние, список игр с источниками, макросы (имя и число шагов), итог поиска с причинами пропуска и последние 20 событий режима (включён, выключен, защита от читов, макрос остановлен, игра добавлена, поиск закончен). В отчёте нет ключей, сказанных фраз и снимков экрана. Пришлите его мне вместе с описанием, что вы делали в игре.

## Библиотека игр (страница «Игры»)

Страница показывает библиотеку как значки на рабочем столе Windows.

- **Главная страница:** кнопки «Найти игры» и «Добавить игру», карточка «Все игры» с числом игр (это число записей библиотеки, а не найденных файлов), поиск, фильтр по жанру, меню «Вид» и 12 недавних или новых игр. Вся библиотека длинным списком на главной не выводится.
- **Все игры:** отдельное окно: заголовок «Все игры — N», поиск, фильтры (жанр, источник), сортировка (по названию, сначала новые, недавно запущенные), меню «Вид», «Добавить игру». Список подгружается порциями по 60 при прокрутке, поэтому окно остаётся быстрым и при 200 играх и больше.
- **Меню «Вид»:** крупные значки (92 px), обычные (56 px), мелкие (28 px, подпись справа в одну строку). Сетка сама перестраивается по ширине окна. Выбранный вид и сортировка сохраняются в настройках программы (`ui`: `games-view`, `games-sort`), а не в списке игр.
- **Действия с игрой:** при наведении (или всегда на сенсорном экране) в углу ячейки две маленькие кнопки: «Запустить» и «Удалить». Клик по самой ячейке ничего не делает.
- **Запуск:** запускается только игра, на которую нажали. Steam-игра, найденная поиском, запускается через Steam (`steam://rungameid/<номер>`; номер проверяется как число). Остальные игры запускаются своим файлом `.exe`: непосредственно перед запуском проверяется, что файл есть, это `.exe` и это программа именно этой игры; запускает Windows (`ShellExecute`, без `cmd.exe`, аргументы защищены кавычками по одному). Если файл программы только угадан по размеру файлов папки, игра не запускается: Jarvis просит выбрать файл. Если файл не найден: «Файл игры не найден. Выберите новый путь к игре» и кнопка выбора нового файла (запись и её ID сохраняются).
- **Добавить игру:** кнопка «Обзор…» открывает системное окно Windows «Открыть файл» (любой диск и папка); путь подставляется в поле, название берётся из имени файла или папки и его можно изменить, жанр выбирается, игра добавляется кнопкой «Добавить». Выбранный файл только проверяется и не запускается. Игра не обязана быть из Steam, Epic Games или GOG. Документы, картинки, архивы и несуществующие файлы не принимаются. Если игра уже есть, дубликат не создаётся: предлагается обновить запись или показать её в библиотеке.
- **Удалить:** убирает только запись библиотеки (и картинку значка, которую Jarvis сам сохранил) после подтверждения «Файлы игры останутся на компьютере». Программа не содержит кода, который удаляет файлы игр, папки магазинов, сохранения или запускает деинсталлятор.
- **ID и данные:** у каждой игры стабильный ID (из ID магазина, иначе из пути, иначе из имени программы; при смене пути ID не меняется). В `game_list.json` добавлены поля `id`, `path`, `store_id`, `verified`, `args`, `added`, `last_launched`, `launches`; старый файл читается без потерь.
- **Дубликаты:** игра считается той же, если совпал ID магазина или нормализованный путь; игры с похожими названиями не склеиваются. Выбранный пользователем путь повторный поиск не заменяет.
- **Значки:** (1) уже сохранённая картинка (`game_icons` в папке данных), (2) значок файла игры средствами Windows (файл только читается), (3) для Steam: картинка, которую Steam уже хранит на компьютере (`appcache/librarycache`), если она есть, (4) аккуратный стандартный значок игры. Из интернета ничего не скачивается.
- **Доступ:** добавление, выбор файла, поиск игр, запуск, новый путь, метка и звук входят в платную часть (Premium) через общую проверку доступа; «Удалить», смена жанра и удаление макроса доступны всегда.

### Что проверено, а что нет

Проверено автоматически (тесты и браузер с подменёнными ответами): ID и дубликаты, поиск и фильтры, сортировка и постраничная выдача на 100 и 200 играх, добавление, удаление только записи (файлы, папка и сохранения остаются), проверка пути, отказ в запуске угаданного файла, безопасные кавычки аргументов, настоящий запуск тестовой программы (Linux), совместимость со старым `game_list.json`, отказы Demo, сборка под Windows. **Не проверено на живой Windows:** системное окно выбора файла, запуск настоящей игры через `ShellExecute` и через Steam, получение значка из `.exe`, значки Steam из кэша, поиск на реальных установках.

## Исправления после первой проверки в игре

- **Руки важнее голоса.** Пока Jarvis держит клавишу («иди вперёд» держит W), он раз в 20 мс сверяет её с настоящей клавиатурой. Если вы нажали противоположную клавишу (S при W, D при A), его клавиша отпускается: слушается ваша рука. Нажатие «назад» также прекращает бег. Боковые клавиши (A/D при W) ходьбу вперёд не отменяют: можно идти по диагонали. Если вы сами отпустили клавишу, которую Jarvis считал зажатой, он это замечает и следующее «иди вперёд» нажмёт её заново. Прыжок и другие клавиши голосовой ход не прерывают. Это работает без перехвата всей клавиатуры: читается только состояние клавиш ходьбы, и только пока режим включён и игра впереди.
- **Оружие.** «Смени оружие» (клавиша `weapon`, по умолчанию Q; в `game_profile.json` её можно поменять, например `"weapon": "1"`), «следующее оружие» и «предыдущее оружие» (колёсико мыши), «первое / второе / третье оружие» или «оружие два» (цифровые клавиши 1–5).
- **Распознавание.** Слова направления понимаются и с типичными ошибками распознавания («иди в перед», «впереть», «иду вперёд», «назат», «налево» и т. п.). Слово «перед» само по себе направлением не считается («перед дверью»).
- **Без ИИ в игре.** Короткая фраза (до пяти слов), которая не является ни командой игры, ни командой компьютера, пока режим включён и игра впереди, больше не уходит к ИИ: ничего не объясняется, на метке над игрой появляется «✗ не понял». Длинные фразы (вопросы) идут обычным путём; чтобы спросить ИИ, выключите игровой режим.
- **Микрофон остаётся открытым.** Пока режим включён, не нужно говорить «Джарвис» перед каждой командой, и пауза в 5 секунд больше не возвращает к слову-активатору. Режим выключается голосом («выключи игровой режим») или кнопкой.
- **Метка показывает, что услышано:** последняя фраза на 4 секунды со значком ✓ или «✗ не понял». Так видно, что именно распознал микрофон.

Проверено автоматически: правила уступки клавиатуре (на подставной клавиатуре), разбор искажённых фраз, оружие, отказ от ИИ для короткой непонятой фразы, текст метки. Не проверено на живой Windows: чтение настоящей клавиатуры, колёсико мыши в игре, реальная работа без слова «Джарвис».

## Прицельный огонь и модель прицела

- **Фразы.** «Огонь», «стреляй», «стрелять», «выстрели», «пли» — обычный выстрел. «Целься в голову» / «целься в корпус» — поднимает прицел и включает помощь прицела для этой части тела. «Прицельный огонь», «стреляй прицельно», «выстрели в голову», «целься и стреляй» — прицел, ожидание, пока перекрестие станет на цели (до полутора секунд), одна очередь и опускание прицела. Если цель не поймана, Jarvis говорит «Цель не вижу» и не стреляет вслепую; если нет модели, он говорит, почему.
- **Без файла модели помощь прицела ничего не видит.** Это главная причина «он не знает, на что стрелять»: Jarvis не умеет находить людей на экране без нейросети-детектора, а готовой модели в программу не вложено. На странице «Игры» → «Помощь прицела» кнопка «Установить модель автоматически» скачивает и ставит официальную модель, а «Выбрать файл модели…» открывает окно Windows. Любой файл сначала проверяется (см. ниже), потом ставится в `aim\player.onnx`; прежний файл сохраняется рядом как `player.onnx.bak-<время>`.
- **Запасной путь, если автоматическая установка недоступна** (на своём компьютере, нужен Python; обычно не нужен — см. «Установка модели внутри Jarvis»): `pip install ultralytics`, затем `yolo export model=yolov8n.pt format=onnx imgsz=640`. Команда скачает веса и создаст `yolov8n.onnx`; класс 0 — «человек» (так и настроено по умолчанию). Лицензия YOLOv8 — AGPL-3.0: для личного использования подходит, встраивать модель в продаваемую программу или раздавать — отдельное решение владельца. Модель, обученная на обычных фотографиях, лучше находит людей в реалистичных играх; для мультяшных игр её стоит дообучить (см. выше раздел про дообучение).
- **Как работает.** Помощь работает на процессоре (DirectML в сборку не входит), только пока удерживается правая кнопка мыши в окне игры, при каждом запуске выключена. Каждые несколько десятков миллисекунд снимается квадрат 640×640 вокруг перекрестия, детектор находит людей, перекрестие плавно подводится к голове (12% высоты фигуры сверху; для «в корпус» — 38%). Не проверено на живой игре.

## «Мой голос» и защита от замкнутого круга

- **Эхо.** Пока Jarvis говорит и ещё 0,7 секунды после, микрофон не слушает; а если распознанная фраза состоит из слов, которые Jarvis сам только что сказал (до 6 секунд после конца речи), она игнорируется. Раньше собственный ответ (или ответ ИИ) мог быть услышан, воспринят как вопрос, получить новый ответ и так по кругу, особенно в «режиме разговора».
- **Мой голос** (Настройки → «Мой голос»): запишите 5 фраз; Jarvis сохранит числовой отпечаток голоса (тембр и высота; звук не хранится). Включите «Слушать только мой голос»: чужие голоса, игра и фильмы игнорируются. «Проверить» показывает, принял бы Jarvis вашу фразу, с расстоянием и порогом. «Мягче / Обычная / Строже» меняет порог. Отказы пишутся в события, три отказа подряд сопровождаются подсказкой в окне. Очень короткие команды из одного слова (например, «стой») без проверки пропускаются.
- **Честно о возможностях.** Это простая экспериментальная защита, а не биометрия: различает голоса по тембру и высоте, на синтетических голосах в тестах отличает мужской голос от женского и от шума, но на настоящих голосах и в шумной комнате я её не проверял. Она может ошибаться на похожих голосах и не защищает от записи вашего голоса. По умолчанию выключена; если вас не узнаёт, поставьте «Мягче» или выключите.

## «Мой голос» и микрофон на пульте (когда в компьютере нет микрофона)

В компьютере без микрофона голос идёт через пульт на телефоне или планшете, поэтому запись образца, проверка голоса и «слушать только мой голос» работают и там: на пульте вкладка **«Ещё» → «Мой голос»**.

- **Запись образца на планшете.** «Записать мой голос»: страница пульта включает микрофон устройства (нужна защищённая страница с https, как для обычного голосового ввода), вырезает ваши фразы по паузам и отправляет каждую на компьютер. Компьютер считает числовой отпечаток голоса и подсказывает следующую фразу (всего пять). Звук нигде не сохраняется.
- **Проверка.** «Проверить мой голос» показывает, принял бы Jarvis фразу, с расстоянием и порогом.
- **Слушать только мой голос.** Когда включено, команды голосом с пульта идут так: страница отправляет на компьютер звук фразы, компьютер сначала сверяет голос с образцом, потом распознаёт фразу сам (офлайн, Vosk) и выполняет её как команду пульта. Чужой голос, фильм и игра отклоняются до распознавания. Тем самым защита действует и для голоса с планшета, а не только для микрофона компьютера.
- **Распознавать речь на компьютере (офлайн).** Отдельный переключатель: даже без проверки голоса распознавание делает компьютер, а не браузер планшета. Тогда у планшета не нужен интернет для распознавания речи. Качество распознавания зависит от модели Vosk на компьютере.
- **Эхо.** Пока ответ звучит на планшете, его микрофон ничего не берёт; фразы, составленные из слов самого Jarvis, отбрасываются компьютером.
- **Окно на компьютере.** Если в компьютере нет микрофона, кнопки записи в «Настройках» отключены с подсказкой идти на пульт.

Проверено автоматически: пульт принимает звук только с секретом ссылки, записывает голос из пяти фраз (на синтетических голосах), отклоняет другой голос до распознавания и пропускает владельца; страница пульта в браузере с поддельным микрофоном режет звук на фразы и отправляет их. **Не проверено:** настоящий микрофон планшета и ваш голос; распознавание Vosk фраз с планшета (качество звука и шум); разрешение микрофона в вашем браузере; работа по туннелю «из любой сети» (звук фразы до 340 КБ).

## Установка модели внутри Jarvis (карточка «Помощь прицела»)

**Что делают кнопки.**
- **«Установить модель автоматически»** — показывает размер загрузки (≈35 МБ), скачивает официальную модель по HTTPS во временный файл `aim\incoming.onnx` (виден прогресс, есть «Отменить»), сверяет **размер и SHA-256** с ожидаемыми, проверяет совместимость и только потом атомарно (переименованием в той же папке) ставит на место. При любой ошибке, отмене или несовпадении суммы временный файл удаляется, а прежняя модель остаётся как была. Повторное нажатие («Переустановить») ставит модель заново; прежний файл сохраняется как `player.onnx.bak-<время>`.
- **«Выбрать файл модели…»** — файл `.onnx` из окна Windows. Расширению не верят: файл копируется во временный, считается его SHA-256, он обязан загрузиться в ONNX Runtime, иметь вход-картинку `float32 1×3×H×W` и выход детектора людей, и дать числа (не NaN) на пробном запуске. Классификатор, «битый» файл или чужая модель отклоняются с причиной. У чужого файла эталона SHA-256 нет, поэтому проверяется только совместимость; в отчёте это так и написано. Модели с внешними файлами весов не поддерживаются.
- **«Проверить модель»** — повторная проверка установленного файла, ничего не меняет на диске.
- **Состояния карточки:** не установлена · скачивание (с процентами) · проверка SHA-256 · проверка совместимости · установка · ошибка установки · модель несовместима · найдена, проверяется · готова (выключена) · включена.
- Установка и проверка идут в отдельных потоках и не блокируют окно. Во время установки помощь прицела выключается.

**Источник и лицензия.** Официальная модель — **YOLOX-s** из репозитория OpenCV Zoo (`opencv/opencv_zoo`), файл `models/object_detection_yolox/object_detection_yolox_2022nov.onnx`, коммит `47534e27c9851bb1128ccc0102f1145e27f23f98`; адрес в программе указывает на этот коммит, поэтому содержимое не может «тихо» измениться. Ожидаемые значения (из LFS-указателя этого коммита): размер 35 858 002 байта, SHA-256 `c5c2d13e59ae883e6af3b45daea64af4833a4951c92d116ec270d9ddbe998063`. Лицензия: **Apache-2.0** (YOLOX, Megvii; OpenCV Zoo). Другие адреса и «зеркала» не используются. Перенаправления разрешены только внутри GitHub (https). Загруженный файл — данные нейросети, а не программа: он не запускается, его читает только ONNX Runtime.

**Среда выполнения.** ONNX Runtime встроен в Windows-сборку (обе редакции, Admin и User): Python, CMD, Ultralytics не нужны. Работает на процессоре; для модели нужно ≈35 МБ диска.

**Какие форматы моделей понимает Jarvis.** Формат определяется по форме выхода и проверяется пробным запуском:
- YOLOv8 / YOLO11: выход `1×(4+классы)×боксы`, вход RGB 0..1;
- YOLOX (как экспортирует OpenCV Zoo): `1×8400×(5+классы)`, сырые смещения клеток и логарифмы размеров (шаги 8/16/32), вход RGB 0..255;
- YOLOv5: `1×боксы×(5+классы)` с готовыми боксами, вход RGB 0..1.
Кадр масштабируется под вход модели, рамки возвращаются в координаты экрана, лишние дубли убираются (NMS), мелкие рамки отбрасываются. Класс «человек» — номер 0 (`aim.class`). **Модель находит человека целиком**: «голова» (12% высоты сверху) и «корпус» (38%) — точки внутри рамки, а не найденные части тела. Точная голова требует модели с точками скелета или модели, обученной на головах.

**Настройки карточки** (хранятся в `aim_settings.json` папки данных поверх `game_profile.json`, его файлы не меняются): устройство (Авто / Процессор / Видеокарта), размер квадрата у прицела (по умолчанию 640), кадров в секунду (30), порог уверенности (45%), наименьший размер человека (24 пикселя). Если компьютер не успевает, пауза между кадрами не меньше половины времени кадра — программа не занимает у игры больше двух третей ядра. Устройство и размер применяются при следующем включении.

**Видеокарта (DirectML).** В обычные установщики не входит: функция `directml` (Cargo) выключена, потому что на реальном железе её не проверить из среды разработки. «Авто» и «Видеокарта» там работают на процессоре, а карточка и отчёт это пишут. **Отдельная экспериментальная сборка:** CI на каждый коммит собирает `Jarvis-DirectML-<дата>_<sha>` (задача `build-directml`): `jarvis-app.exe` с `--features directml` и библиотеки рядом. Это не установщик: закройте Jarvis, сделайте копию папки установленной программы, скопируйте эти файлы поверх, в карточке выберите «Видеокарта (DirectML)» и нажмите «Проверить модель»: в отчёте будет написано, на чём реально работает модель. Если видеокарта не запустится, программа сама вернётся на процессор и скажет об этом. На сервере CI видеокарты нет, поэтому там проверяется только то, что сборка собирается и модель продолжает работать; **быстрее ли видеокарта на вашем ПК, покажет только ваш отчёт** — для маленькой модели выигрыш не гарантирован.

**Снимок экрана.** Берётся квадрат вокруг центра **окна игры** (оконный и «окно без рамки» режимы, любое разрешение и положение окна; размер подстраивается под окно). Окно свёрнуто, закрыто, не впереди (Alt+Tab) — помощь ждёт и ничего не делает. Чёрный или однотонный кадр (защищённое окно, «настоящий» полноэкранный режим) или долгий ряд ошибок снимка — помощь выключается сама и пишет причину, а не ждёт бесконечно. Жёсткого «монопольного» полноэкранного режима, окон с защитой от снимков и игр с защитой от читов обойти нельзя и не нужно: ничего не внедряется в игру, не читается её память; при запущенной защите от читов игровой режим и помощь прицела не включаются.

**Безопасность.** Выключена при каждом запуске; включается только явно («включи помощь прицела» или кнопка); «Выключить», «стой», выход из игрового режима и защита от читов останавливают её сразу, фоновый поток завершается сам. Кнопки установки, проверки и настроек — часть Premium-функций игровой библиотеки (в Demo отказ с пояснением), как и сам игровой режим.

**Диагностика.** Карточка «Помощь прицела» в разделе «Диагностика» и кнопка **«Копировать отчёт»** в карточке: модель (название, источник, лицензия, SHA-256, результат проверки), среда выполнения, устройство, DirectML в сборке, захват, время кадра, число найденных людей, последняя ошибка. Ключей, снимков экрана и голоса в отчёте нет.

**Что проверено, а что нет.** Автотестами (Linux и Windows-сборка компилируется): разбор трёх форматов выхода, предобработка и обратное масштабирование координат на искусственных изображениях, NMS, выбор цели, шаг мыши, ONNX Runtime на маленьких тестовых моделях всех трёх видов, отказ для классификатора и «мусорного» файла, установка из подставного источника (хорошая, обрыв, неверная сумма, неверный размер, отмена, повторная установка, сохранение прежней модели при каждом сбое), ручная установка, настройки, пауза при медленном кадре, чистая остановка, отчёт без секретов, карточка диагностики. **Не проверено:** загрузка настоящего файла с GitHub и сверка его суммы на живой сети; запуск настоящей YOLOX-s в программе; захват экрана и поведение в живой игре на Windows; скорость на конкретном процессоре. Это можно проверить только на вашем компьютере: нажмите «Установить модель автоматически», затем «Проверить модель» и пришлите «Копировать отчёт».
