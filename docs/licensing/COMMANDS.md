# Инвентаризация команд и уровней доступа

Файл создан по `resources/commands/*/command.toml` и `resources/access.toml`. Правило: всё, чего нет в списках FREE / SYSTEM / ADMIN, — **PREMIUM** (новая команда платная по умолчанию, пока владелец не внесёт её в `access.toml`).

Всего команд: **154**. FREE: **34**, SYSTEM: **8**, ADMIN: **0**, PREMIUM: **112**.

Кроме команд, платными считаются кнопки окна: программы (`ui_app_launch`), поиск и открытие файлов (`ui_file_search`, `ui_file_open`), доступ из интернета (`ui_remote_tunnel`), проверка экрана (`ui_screen_check`), картинка в чате (`ui_chat_image`), запуск сценариев (`scenario_run`).

Как изменить: перенесите `id` команды в нужный раздел `resources/access.toml` и пересоберите программу. Тест `the_lists_name_real_commands_and_nothing_dangerous_is_free` не даст сделать бесплатной команду высокого риска или запуск программ.
