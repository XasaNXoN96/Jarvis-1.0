# Ручная проверка на реальном ПК и телефоне

Всё ниже проверено только автоматически (тесты, Chromium на подставных данных, Windows CI). Ни один пункт на настоящем ПК, телефоне, O1, Home Assistant, WhatsApp/Telegram не проверялся. Отмечайте результат справа: ✔ / ✘ + что увидели. Если что-то не так — пришлите номер пункта и что было на экране.

Версия: ветка `dev/punkt-9-11-13`, установщик из последнего зелёного Windows CI.
