«Проверено» = автотесты Rust (jarvis-core ~900 тестов, обе редакции), Windows `cargo check --tests`, CI на Windows и браузерный смоук-тест страницы (Playwright, заглушки сервера).

Последнее обновление: пачка 6 (форма картинок, поиск по событиям диагностики, PDF в базе знаний, экран ПК на телефоне, пароль на опасные команды).
