# Чек-лист владельца: проверка этапа 2 на настоящем Windows-ПК

Всё ниже не проверено автоматически. Установите сборку из CI (артефакт `Build Windows installer` для коммита этапа 2) и пройдите пункты. Ожидаемый результат — в скобках. При ошибке: «Диагностика → Копировать диагностический отчёт» (в нём нет ключей и паролей) и опишите шаги.

## Что чем проверено
| Область | Автотесты (Rust) | Chromium (имитация сервера) | Нужен физический ПК |
|---|---|---|---|
| Окно WebView2, шрифты, DPI | — | вёрстка при 100/125/150/200 % и ширине 700–1920 px: нет горизонтального переполнения | да: настоящее окно и настоящий масштаб Windows |
| Клавиатура | — | Tab доходит до поиска и всех фильтров журнала, ввод с клавиатуры фильтрует | да: Tab по всему окну в WebView2 |
| Журнал безопасности | поиск, фильтры, «вся операция» | поиск, фильтры, пустое состояние, счётчик, «вся операция» | просмотр на живых записях |
| Память/дневник: удаление, правка, отмена | правила, возврат, отказ при изменении | кнопка «Отменить» | голос «забудь …» / «верни как было» |
| Микрофон | логика наблюдателя, журнал событий | — | да: всё реальное |
| winget | слот установки, статусы, отмена (чистая логика) | — | да: реальный winget |
| ИИ | ошибки, тайм-ауты, отмена (имитация) | — | да: реальный ключ |
| Игры/сессия | сессия, сон, смена игры | — | да: настоящая игра |
| Монитор | кэш, «Недоступно», частота экрана (логика) | — | да: NVIDIA, 144 Гц, AMD/Intel |

## Шаги
**1. WebView2 и DPI.** Масштаб Windows 100 %, 125 %, 150 %, 200 % (Параметры → Дисплей). Откройте Настройки → «Ещё» → Журнал безопасности, затем Главная, Программы, Команды, Игры. (Нет горизонтальной прокрутки, текст не обрезан; в «Основное» переключатель браузера переносится на вторую строку в узком окне.) Потяните границу окна до минимума и обратно. (Ничего не разъезжается, окно возвращается в норму.)

**2. Клавиатура.** В журнале безопасности: Tab → «Поиск» → 4 списка → вернуться; наберите слово (список фильтруется через четверть секунды); стрелками смените «За час». (Фокус виден, из поля можно выйти Tab, ловушек нет.)

**3. Журнал безопасности.** Скажите/введите команду, затем выполните с телефона опасную команду. (Записи с источниками «голос»/«телефон»; «вся операция» показывает записи одной команды по порядку; в записях нет текста фраз, путей, ключей.) Фильтр, которому ничего не соответствует: «ничего не найдено (всего записей: N)».

**4. Память и дневник.** Добавьте запись, удалите → «Отменить» (запись вернулась). Измените запись дважды, отмените первую правку (должен отказать: «Запись уже изменена…»). Правка в пустую строку (отказ). Скажите «забудь …», затем «верни как было». Дневник: Изменить, «Копировать всё». Важно: после очистки истории действий отмена уже невозможна.

**5. Микрофон.** USB-микрофон: выдернуть на 30 с и вернуть. (Диагностика → «Последние события» → «Микрофон: звук не приходит…», «переоткрываю микрофон…», «звук идёт».) Выключить микрофон в трее/командой (событие «микрофон выключен»). Заблокировать Windows и разблокировать; усыпить и разбудить ПК. Открыть микрофон в другой программе в монопольном режиме. Сказать «Джарвис» с разных расстояний. Если слово не сработало: Диагностика → «Поток звука с микрофона» — что написано.

**6. Собственный голос.** Пусть Jarvis что-то говорит; он не должен срабатывать сам на себя. Стоп-слово во время ответа — речь прерывается.

**7. winget.** Каталог Windows: найти и установить небольшую программу; нажать «Отмена» посреди загрузки (статус «Отменено» только после остановки процесса). Отключить сеть во время загрузки (статус «Ошибка», не «Готово»). Нажать «Установить» дважды подряд (вторая отклоняется: «Уже идёт другая установка»).

**8. ИИ.** Неверный ключ (понятная ошибка, без ключа в тексте), лимит запросов, обрыв сети посреди ответа (ответ не зависает, есть ошибка), «Стоп» во время потока, восстановление после возврата сети. Проверьте OpenAI-совместимый API и Gemini.

**9. Игровая сессия.** Запустить игру из списка (Steam/Epic/GOG), включить режим, сказать игровую команду; закрыть игру (Статистика: сессия записана после ~минуты отсутствия); усыпить ПК с игрой на экране и разбудить (сессия должна закончиться на моменте сна, а не длиться часы). Известно: если закрыть Jarvis во время игры, текущая сессия не сохранится.

**10. Монитор.** Главная: ЦП/ОЗУ/диск; NVIDIA — видеокарта, видеопамять, температура, частота; «Частота экрана» (например 144 Гц) — это текущий режим экрана; на AMD/Intel GPU — «Недоступно» с причиной. Нагрузка Jarvis в простое не должна заметно расти (Диспетчер задач).

## Известные ограничения (не скрываются)
- Номер операции связывает только записи журнала безопасности; события диагностики его не несут.
- Незавершённая игровая сессия теряется, если закрыть Jarvis во время игры.
- Отмена: только для удаления и правки памяти/дневника и прежних действий («добавил», «задание», «картинка», «правка файла»); не откатывает запущенные программы, отправленные сообщения, данные в синхронизируемой папке или резервных копиях; перестаёт работать после очистки истории действий или если запись уже менялась.
- Частота экрана — текущий режим основного экрана, не живая частота при VRR.
- GPU-метрики только NVIDIA.

### До удаления старого приложения (данные сами не сохранятся)
Резервное копирование приложения выключено, удаление стирает всё, что хранит телефон: адрес ПК, личный секрет привязки, тему и сферу, выбранные на телефоне, переключатели страницы пульта («озвучка на телефоне», «записывать голос на ПК»). На ПК остаются память, история, настройки Jarvis и «Мой голос». Поэтому до удаления:
1. Запишите адрес ПК (например `192.168.1.10`).
2. На ПК: «Система» → «Пульт телефона» → «Привязанные устройства» — запишите имя старого телефона (его запись нужно будет отозвать, см. шаг 13).
3. Запишите или сфотографируйте, что важно из переключателей и темы на телефоне.
4. Перед установкой нового Windows-пакета сохраните копию папки данных Jarvis. Её точный путь и то, что установщик сохраняет данные при обновлении, я не проверял — не полагайтесь на сохранность без копии.
5. Старое приложение (подписано прежним ключом) поверх нового не обновляется: удалите его и поставьте Release APK. Прежние APK (#1–#4 и сборки `-LEGACY-KEY`) считайте недоверенными.

### Шаги
**Подготовка.**
1. ПК: установите Windows-пакет (см. артефакты), запустите Jarvis → «Система» → «Пульт телефона» → включите. Проверка: видна строка «Отпечаток ПК: …» (6 групп по 4 символа), нет красной плашки про http. Если вместо неё ошибка — пришлите диагностику.
2. Телефон: удалите старое приложение (раздел выше), установите Release APK (разрешите установку из этого источника), запустите.

**Привязка вручную — с проверкой отпечатка (основной путь, пропускать нельзя).**
3. ПК: «Привязанные устройства» → «Привязать телефон по коду» (код живёт 5 минут).
4. Телефон: введите только адрес ПК. Ожидаемо: окно «Проверьте отпечаток компьютера». Пока вы не подтвердили, страница пульта не открывается и ничего не отправляется.
5. **Сверьте отпечаток символ в символ** с тем, что показано на ПК (строка «Отпечаток ПК»). Совпал — «Совпадает». Не совпал — «Не совпадает»: соединение закрывается, дальше не идти и сообщить.
6. Откроется страница привязки: введите код из шага 3. Ожидаемо: пульт открылся, текстовая команда с телефона выполняется на ПК.

**Привязка по ссылке из QR (отпечаток приходит в ссылке).**
7. Сначала на экране ввода адреса нажмите «Забыть прежний компьютер (сбросить отпечаток)», на ПК снова нажмите «Привязать телефон по коду».
8. QR на ПК (в карточке «Система» или в «Настройки → Подключения → Пульт телефона») прочитайте камерой телефона или Google Lens и скопируйте текст ссылки вида `https://адрес:9713/#pin=sha256/…&c=…`. Встроенного сканера в приложении нет, а текст этой ссылки окно ПК не показывает (известное неудобство, см. список исправлений ниже). Вставьте ссылку в поле адреса приложения. Ожидаемо: отпечаток не спрашивается (он в ссылке), код подставлен в поле, вы нажимаете «Привязать». Если ссылку получить не удалось — пройдите шаги 3–6.

**Смена адреса.**
9. Смените IP ПК (другая сеть или переподключение). На телефоне «Сменить компьютер» (в ссылке на экране «Нет связи с компьютером») → новый адрес. Ожидаемо: отпечаток не спрашивается, повторная привязка не нужна.

**Подмена и повторная привязка.**
10. ПК: «Безопасность соединения» → «Сменить ключ ПК» (подтвердить; запишите новый отпечаток).
11. Телефон: откройте приложение. Ожидаемо: отказ «Это не тот компьютер…», кнопки «открыть всё равно» нет.
12. Нажмите «Это другой компьютер: забыть прежний отпечаток», введите адрес, **сверьте новый отпечаток** с ПК, привяжите заново (шаги 3–6).

**Отзыв.**
13. ПК: «Привязанные устройства» → «Отозвать» у этого телефона. Ожидаемо: телефон теряет доступ и показывает экран привязки. Заодно отзовите запись старого телефона (из раздела «До удаления»).

**http.**
14. В браузере ПК откройте `http://адрес:9713/`. Ожидаемо: «Обычный http отключён» (код 426). «Разрешить обычный http» включается только после подтверждения и показывает красную плашку; после проверки выключите.

**Android 8–9 (API 26–28), если есть такой телефон:** повторить шаги 3–6 и 7–8.

При ошибке: «Диагностика» → «Копировать диагностический отчёт» (без ключей и паролей), «Настройки» → «Журнал безопасности», модель телефона и версия Android. Статус всех шагов выше: **не выполнено**.

### Неточные тексты в программе (исправления кода — отдельной задачей, в этой правке не делались)
1. `MainActivity.java`, подсказка на экране ввода адреса: говорит «Настройки → Подключения → «Пульт телефона» … нажмите «Привязать телефон по коду»»; кнопка находится в «Система» → «Пульт телефона» → «Привязанные устройства».
2. `MainActivity.java`, окно отпечатка: «Настройки → Пульт телефона → Безопасность соединения» → должно быть «Система → Пульт телефона → Безопасность соединения».
3. `remote_page.html`, окно привязки: «Настройки → Телефон → «Привязать телефон по коду»» → «Система → Пульт телефона → Привязанные устройства».

5. Окно ПК не показывает текст ссылки привязки (`#pin=…`), только QR: нужна строка с кнопкой «Копировать ссылку привязки».
