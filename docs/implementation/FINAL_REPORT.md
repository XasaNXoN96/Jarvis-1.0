## Известные проблемы
- `gui-check` (информационный) красный и раньше.
- Пароль владельца не охраняет команды Lua и запуск программ; нет экрана входа при старте.
- Дублирующие запуски команд защищены существующим `guard`, но не изучены для всех новых каналов.
