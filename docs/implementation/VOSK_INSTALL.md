# Установка модели распознавания речи (Vosk) из программы

Причина проблемы «на чужом ПК не все голоса и функции»: малый установщик не содержит ни модели Vosk, ни голосов Piper; голоса Piper программа уже умела докачивать, модель речи — нет (только полный установщик). Теперь модель ставится из «Настройки → Компоненты».

- Модели (ru `vosk-model-small-ru-0.22`, en `vosk-model-small-en-us-0.15`, uk `vosk-model-small-uk-v3-nano`) берутся с `alphacephei.com/vosk/models`. Архив принимается только при точном совпадении размера и SHA-256 (значения получены workflow `vosk-model-hash.yml` из реальных файлов).
- Распаковка делается самой программой (не оболочкой): каждый путь проверяется (без `..`, дисков, обратных слэшей, ссылок), лимит 3000 файлов и 700 МБ, всё в промежуточную папку, на место — только если там есть `am/final.mdl` и `conf/model.conf`. При любой ошибке ничего не остаётся.
- Удаление убирает только папку именно этой модели.
- После установки нужен перезапуск Джарвиса (модель загружается при старте).
- Диагностика при отсутствии модели теперь говорит, куда нажать.

Проверено: автотесты (таблица, хорошие и плохие архивы, ссылки, неверный размер/хеш, список компонентов), проверка типов для Windows. НЕ проверено: реальная загрузка (из среды разработки сервер моделей недоступен), работа на чистом ПК. Голоса Piper по-прежнему без закреплённых хешей файлов голоса (см. `docs/SECURITY-DOWNLOADS.md`).
