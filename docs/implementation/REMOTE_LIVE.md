# Jarvis Remote: управление мышью и клавиатурой (40.4) и веб-камера ПК (40.6)

Решение владельца: обе функции нужны. Они опасные, поэтому устроены так.

## Правила
- **Две отдельные способности** в центре разрешений, обе **выключены по умолчанию**: `remote_input` и `remote_camera`. Включает только владелец (под замком `owner::guard`).
- **Явный старт.** Одной включённой способности мало: телефон должен нажать «Включить» (`/input-start`, `/camera-start`). Скрытого включения нет.
- **Сеанс сам заканчивается** (`live.rs`): мышь — через 60 с без действий или 10 мин; камера — через 20 с без запросов кадра или 10 мин. Время подставляемое — правила проверены тестами без ожидания.
- **Видимость.** Пока сеанс идёт, вверху окна Jarvis красная полоса с названием («Телефон управляет мышью…» / «…смотрит через веб-камеру…») и кнопкой «Выключить» (`remote_live_stop`). Полосу нельзя скрыть из пульта. Плюс важное уведомление и запись в журнал (`audit`), у камеры — лампочка самой камеры.
- **Проверка на каждом действии на ПК.** Способность перепроверяется при каждом действии/кадре; выключили — сеанс закрывается сразу. Сеанс закрывается также при остановке пульта и отзыве телефона.
- **Защита от повторов.** Все изменяющие запросы (`/input-start`, `/input-stop`, `/input`, `/camera-start`, `/camera-stop`) несут время и уникальный номер (`replay.rs`).
- **Мышь/клавиатура ограничены.** Только: клик/двойной/правый по нормализованной точке (0–1), прокрутка 1–20 строк, ввод текста до 200 символов без управляющих, клавиши из белого списка (Enter, Esc, Tab, Backspace, Delete, стрелки, Home/End, PageUp/Down, F5) и сочетания Ctrl+C/V/X/A/Z/Y/F/S, Alt+Tab/←/→. Win+R, Win+X, Ctrl+Alt+Del, Ctrl+Shift+Esc запрещены (`policy::judge_keys`). Не чаще раза в 80 мс. Текст нажатий в журнал не пишется.
- **Камера.** Нет записи и хранения: один кадр на запрос, не чаще 4 в секунду, качество low/medium/high (ширина 320/640/1024). Список камер и выбор — с телефона.

## Что проверено
- Автотесты (Linux, подставные «руки» и «камера», реальная мышь/камера не задействуются): способности выключены по умолчанию; без старта ничего не работает; выключение способности и отзыв телефона закрывают сеанс; повтор запроса не выполняется; запрещённые клавиши и неверные данные отклоняются до действия; лимит частоты; конец по тишине и по максимальному времени.
- Chromium: страница телефона (старт только по нажатию, точка касания, клавиши/текст/прокрутка, выбор камеры, отказ при выключенной способности, остановка при закрытии) и красная полоса ПК.
- Код Windows (SendInput, Media Foundation через nokhwa) проходит проверку типов под `x86_64-pc-windows-gnu` (сборка Windows CI — см. ниже в отчёте после запуска).

## Что НЕ проверено
- Реальная мышь/клавиатура ПК, реальная веб-камера и реальный телефон. Камера: безопасность передачи объекта камеры между потоками (`unsafe impl Send`, доступ только под замком) и работа Media Foundation на конкретных драйверах не проверялись.
- Экран входа Windows, окна UAC и окна с правами администратора: SendInput на защищённый рабочий стол не работает. Это ограничение Windows, обхода нет и не будет.
- Передача идёт по HTTPS-каналу пульта (локальная сеть/туннель); картинка экрана и камеры — base64 в JSON, это не видеотрансляция.
