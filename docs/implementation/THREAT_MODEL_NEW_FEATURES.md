# Модель угроз новых функций (дополнение к `docs/SECURITY-MODEL.md`)

Что защищено, от кого и чем — только для кода, добавленного по плану 41 функции. Общая модель окна/токена/файлов — в `SECURITY-MODEL.md`.

| Часть | Что защищаем | От кого | Чем | Что НЕ утверждается |
|---|---|---|---|---|
| Пароль владельца (`owner.rs`) | защищённые действия: отправка сообщений, удаление памяти/контактов, расписание, разрешения, установка программ, умный дом | человек у компьютера, который не знает пароль; перебор | PBKDF2-HMAC-SHA256 (210 000 кругов, соль 16 байт), пароль нигде не хранится; пауза после 5 неверных попыток (30 с, до 15 мин), счётчик в файле — перезапуск не сбрасывает; код восстановления (хранится только хэш) | процесс того же пользователя Windows может читать файлы Jarvis и менять их; пароль голосом не вводится, чужой голос защищённое не получит, но «разблокировано» действует 15 минут для окна |
| Центр разрешений (`perms.rs`) | способности Jarvis | ошибка/злоупотребление командой | каждый обработчик спрашивает `perms::check` до действия; «Установка программ» и «Умный дом» выключены по умолчанию; переключение требует пароль, если он задан | не изолирует процесс: это проверка внутри программы |
| Память/дневник (`memory.rs`, `notes.rs`) | секреты пользователя | утечка в файл | пароли, ключи, токены, номера карт не записываются (`looks_secret`) | эвристика: нестандартный секрет можно записать намеренно |
| Мессенджер (`messenger.rs`) | чужие сообщения «от имени» пользователя | случайная/ложная команда | подтверждение «да» по умолчанию, окно ожидания 120 с, состояния без ложной «отправлено», повторная отправка невозможна | `manual-send-required`: Jarvis не знает, нажал ли пользователь «Отправить» |
| Перевод (`translate.rs`), база знаний (`kb.rs`) | инструкции в чужом тексте | prompt-injection из документа/перевода | текст — данные в ограждении `<documents>`, закрывающий тег в тексте ломается; перевод с потерей числа/ссылки отвергается | модель может ошибиться; мы лишь не даём тексту стать командой для Jarvis |
| Каталог программ (`progsearch.rs`) | установка недоверенного ПО | подмена источника, инъекция аргументов | только `--source winget` (контроль SHA-256 делает winget), идентификатор и запрос проходят строгую проверку, установщик с видимым окном (не silent), требуется разрешение + клик | проверку подписи издателя делает winget/Windows, не Jarvis |
| Умный дом (`smarthome.rs`) | двери, замки, сигнализация | голосовой подбор | управляются только свет, розетки, вентиляторы, шторы, медиаплееры; токен хранится через DPAPI | локальная сеть пользователя считается доверенной |
| Расписание (`scheduler.rs`) | двойной запуск, лавина | сбой, перезапуск | задание «занимается» до запуска (запись состояния раньше выполнения), пропуск старше часа, не чаще раза в минуту | выполняется как фраза через общий вход `Script` — все проверки команд применяются |
| Генерация картинок (`imagegen.rs`) | запись файла из ответа сервера | враждебный провайдер | файл сохраняется только если первые байты — PNG/JPEG/WebP, лимит 25 МБ, только https-ссылки | видео не поддерживается |

Чего в проекте НЕТ намеренно: самоуничтожения, скрытого наблюдения, обхода античитов, фоновой записи клавиатуры вне явного мастера.

## Дополнение этапа 1 (по результатам аудита 22.10.2026)
| Часть | Что защищаем | От кого | Чем | Что НЕ утверждается |
|---|---|---|---|---|
| Двери и риск (`origin.rs`, `policy.rs`) | опасные операции | чужой запрос с телефона/Telegram, задание, созданное с телефона | `high` вне подтверждённой команды удалённая дверь не выполняет; задание хранит дверь создателя | дверь — не доказательство личности; среднее (`medium`) с телефона разрешено и пишется в журнал |
| Запросы телефона (`replay.rs`, `remote.rs`) | повтор записанного запроса | тот, кто записал трафик | время ±120 с + уникальный номер, номера в файле (переживают перезапуск), дубликат не выполняется, лимит 30/10 с | **секрет устройства по http виден слушающему сеть: он может слать новые запросы** — нужен https или VPN |
| Журнал (`audit.rs`) | разбор «кто и что просил» | — | имена и решения без текста фраз, путей, паролей; 500 записей | журнал лежит рядом с остальными файлами пользователя: процесс того же пользователя может его править |
| Lua `jarvis.http` | компьютер и локальная сеть | изменённый пакет команд | только интернет-адреса, перенаправления проверяются | подмена DNS между проверкой и запросом не отслеживается |
| Пароль владельца (`owner.rs`) | защищённые действия | перебор, параллельные попытки | PBKDF2 210 000, 5 свободных попыток, паузы до 15 мин, общая блокировка проверки | разблокировка действует 15 минут для всех дверей процесса; локальный процесс может удалить `owner.json` |
| Android (`android/`) | запуск от имени приложения | подделка обновления | ключ — только из секретов CI; пакеты со старым публичным ключом помечены `-LEGACY-KEY` | ключ `android/keystore/jarvis-sideload.jks` скомпрометирован (публичный репозиторий) до ротации |
