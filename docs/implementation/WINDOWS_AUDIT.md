# Этап 2: аудит Windows-приложения

Начальный коммит этапа: `bdc1fe2`. Этап ещё идёт; здесь записано только то, что проверено и сделано. Физический ПК с Windows не использовался: всё ниже проверено автотестами (Linux, обе редакции), `cargo check`/`--tests` под `x86_64-pc-windows-gnu` и Windows CI.
