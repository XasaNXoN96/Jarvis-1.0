# Object Interaction Engine (работа с объектами голосом)

Расширение существующих механизмов Jarvis, а не параллельная система: те же двери (`origin`), политика (`policy`), безопасные
файлы (`safefs`), сессии (`session`), подтверждения, Lua-пакеты и ИИ (`ai`).

## Состав
| Модуль | Роль |
|---|---|
| `objects.rs` | Автомат состояний IDLE · APP_OPEN · OBJECT_ACTIVE · DICTATION · AI_TASK · AWAITING_CONFIRMATION · PAUSED · ERROR_RECOVERY (таблица переходов `next`, всё остальное — ошибка), контекст объекта, задача ИИ с флагом отмены (поздний ответ отбрасывается), стоп/пауза/отмена/продолжение, классификатор слов «стоп/пауза/отмена/продолжим/да/нет» по состоянию, проверка окна (`Probe`/`verify`), очистка истории от секретов |
| `resources/commands/assistant/office.lua` + `office.ps1` | Адаптеры Word / Excel / Блокнот (уже были); теперь синхронизированы с автоматом; стоп/пауза/продолжим; потеря объекта; ИИ над текстом Word |
| `docai.rs` | ИИ над текстом документа: исправить ошибки, официальный стиль, перевод, сокращение, вступление, объявление |
| `codeobj.rs` | VS Code + Python: файл, проект, код от ИИ, правка, откат, проверка синтаксиса |
| `ui.rs` / `ui_page.html` | Строка объекта на главной (`#h-obj`) и кнопка «Стоп» (`object_stop`) — только факты автомата |

## Правила
* «Стоп» внутри диктовки — команда только если это **вся** фраза; «он сказал стоп и ушёл» — текст.
* Стоп: диктовка заканчивается, генерация отменяется, вопрос снимается, программа и документ остаются открытыми; контекст хранится; «Продолжим?» → «да» (программа, документ, файл проверяются заново) / «нет» (ничего не закрывается).
* Пауза — то же без вопроса; Отмена — только текущая операция, объект остаётся активным.
* Замена текста документа — только после «да» и только если текст не менялся с момента чтения (хеш); результат читается обратно.
* Файл кода: новый — `create_new` (существующий не затирается); правка — только если файл не менялся с чтения; большое изменение — после «да»; «верни как было»; запись проверяется чтением; `ast.parse` для синтаксиса; **код не запускается**.
* Файл или запрос с ключом/паролем в ИИ не отправляется. Фразы с телефона/Telegram этот механизм не берут.

## Что НЕ реализовано (честно)
Excel (ИИ-формулы, диапазоны, массовая замена), PowerPoint, расширенные операции Проводника и браузера над объектом, Telegram/медиа как объекты, запуск сгенерированного кода, запасной ИИ-провайдер (при недоступности запрос сохраняется для «повтори»). Существующие команды этих программ работают как раньше.

## Проверки
Логика: `cargo test -p jarvis-core` (автомат, контекст, классификатор, Word/Блокнот на поддельном Office, VS Code с подставным ИИ). Реальные Word/Excel/VS Code/микрофон/ИИ — только вручную, см. `docs/MANUAL-CHECKLIST.md`.
