📨Уведомления других программ

        Джарвис может показывать и читать уведомления мессенджеров, почты и других программ — только с вашего разрешения и разрешения Windows (Windows 10 1809+ и Windows 11). При включении Windows может спросить разрешение; без него ничего не читается. Не все программы отправляют уведомления так, чтобы их можно было прочитать, а обычным (не из Microsoft Store) программам Windows иногда не даёт доступ совсем — тогда это будет видно в статусе. Тексты уведомлений остаются на этом компьютере: не сохраняются на диск, не попадают в историю и не отправляются в ИИ или в интернет.

Джарвис сам опрашивает Telegram — входящие порты на компьютере не открываются. Тексты команд и ответов проходят через серверы Telegram. Бот слушается только одного привязанного аккаунта.
        
1. Токен ботасоздайте бота в Telegram у @BotFather (команда /newbot) и вставьте токен сюда. Он хранится в зашифрованном виде и больше не показывается
