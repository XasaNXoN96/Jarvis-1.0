ПРОВЕРОЧНЫЙ СЕРВЕР ЛИЦЕНЗИЙ ДЛЯ ЭТОГО КОМПЬЮТЕРА

Что это: тот же сервер лицензий, что будет в боевой работе, но запущенный у вас на компьютере (только 127.0.0.1, без HTTPS).
Нужен, чтобы попробовать менеджер лицензий в Jarvis Admin: создать ключи, тарифы, увидеть «Архив ключей».

1. Распакуйте архив в любую папку (например, на рабочем столе).
2. Запустите local-license-server.ps1 (правая кнопка -> «Выполнить с помощью PowerShell»).
   Если Windows пишет, что запуск скриптов запрещён: откройте PowerShell в этой папке и выполните
   powershell -ExecutionPolicy Bypass -File .\local-license-server.ps1
3. При первом запуске в окне появится ТОКЕН АДМИНИСТРАТОРА (jla_...). Скопируйте его: повторно он не показывается.
4. В Jarvis Admin откройте «Лицензии»: адрес  http://127.0.0.1:8787  , токен — вставьте, «Сохранить».
5. «Создать ключи»: выберите тариф, «Создать». Ключи покажутся один раз.
6. Окно со скриптом держите открытым: закроете, и сервер остановится. Данные хранятся в
   %LOCALAPPDATA%\JarvisLicenseServerTest (база и секреты); повторный запуск ничего не сбрасывает.

ОГРАНИЧЕНИЕ. Установщик Jarvis User из CI собирается без адреса и без открытого ключа сервера, поэтому он не сможет активироваться
на этом проверочном сервере. Адрес и открытый ключ вшиваются в программу при сборке (JARVIS_LICENSE_URL, JARVIS_LICENSE_PUBKEY):
иначе любой мог бы направить программу на свой сервер. Открытый ключ вашего проверочного сервера печатается при каждом запуске
(строка «публичный ключ для сборки Jarvis User»). Для проверки активации нужна отдельная сборка User с этими значениями.
